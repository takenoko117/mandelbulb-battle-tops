# Mandelbulb Battle Tops

名前を入力すると、その名前だけのマンデルバルブ・コマが生まれるフラクタル・コマ・バトル。
同じ名前なら、いつでも同じコマになります。

**▶ プレイ:** https://takenoko117.github.io/mandelbulb-battle-tops/

## モード
- **軸あり（競技コマ）** — 金属の軸とリングを備えたコマ。名前から生まれたステータスで戦い、必殺技「バルブ・オーバードライブ」も使えます。
- **軸なし（形状×物理）** — フラクタル本体だけのコマ。質量・慣性モーメント・臨界回転・接地面・外周の刃をすべて形状から実測し、物理演算だけで戦います。強い名前を探そう。

## 操作
| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印 | 画面左側をドラッグ |
| シュート | SPACE / クリック | タップ |
| ダッシュ | SPACE | 画面右側をタップ / DASH |
| オーバードライブ（軸ありのみ） | E / SHIFT | OD |
| カメラ（タイトル・対戦前画面） | ドラッグ / ホイール | ドラッグ / ピンチ |
| フォトモード | P | 📷 |

## 技術
WebGL2 のレイマーチングでマンデルバルブを直接描画しています（GGX シェーディング、薄膜干渉、ソフトシャドウ、TAA、ブルーム）。
ビルド不要の静的サイトです。`index.html` を開くか、任意の静的サーバーで配信してください。

# メタ認知診断

16問のクイズと毎問の「自信度」から、人間・社会・感情・自分をどれだけ科学的に理解しているか、そして自分の理解度を正しく見積もれるかを測る診断ゲーム。メタ認知タイプ（9種）とメタ認知偏差値が出て、X・LINE・画像で結果を共有できます。

**▶ プレイ:** https://takenoko117.github.io/mandelbulb-battle-tops/metacognition/

ファイルは `metacognition/index.html` の1枚だけです。
